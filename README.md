# Password Strength Analyzer

A beginner-friendly Python project that checks a password against basic strength rules.

## Features
- Checks password length (8 characters or more)
- Checks uppercase and lowercase letters
- Checks numbers and special characters
- Gives a simple strength rating
- Suggests improvements

## Requirements
- Python 3
- No external libraries required

## How to Run
1. Extract the ZIP file.
2. Open the `Password_Strength_Analyzer` folder in VS Code.
3. Open the terminal.
4. Run `python main.py` (or `py main.py` on Windows).
5. Enter a test password when prompted.

## Note
This is an educational project. Its rating is a simple rule-based estimate, not a guarantee that a password is secure. Do not enter or share your real password in an untrusted program. This version does not store passwords or check password reuse.
